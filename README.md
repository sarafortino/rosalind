# Rosalind

My solutions to [Rosalind](https://rosalind.info) bioinformatics problems, written in Python as Jupyter notebooks.

Each notebook follows the same structure: biological background, problem, approach, solution, test on the sample dataset, and what I learned.

## Run locally

```bash
conda env create -f environment.yml
```

Then open a notebook in VS Code or Jupyter and select the `rosalind` kernel.
